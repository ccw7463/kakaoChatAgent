# 08. 시점 인식과 검색 최신성

커밋 `464f983`.

## 증상

배추 시세를 물었는데 작년 자료로 답했다. 원인이 두 가지였다.

## 1. 날짜 정보가 검색어 생성에만 있었다

`{today}`가 검색 라우팅 프롬프트에만 있고, **시스템 프롬프트와 답변 생성 프롬프트에는
없었다.** 답변을 만드는 시점에 모델은 오늘이 언제인지 몰랐고, 학습 시점 연도를 현재로
착각할 수 있었다.

두 곳 모두에 오늘 날짜를 넣고, *"학습 시점의 연도를 현재라고 착각하지 마세요"* 를
명시했다. 답변 생성에는 추가로:

- 여러 시점의 자료가 섞이면 가장 최신 자료 기준으로 답하기
- 수치나 시세는 **언제 기준인지 함께 밝히기**
- 오늘 기준으로 오래된 자료뿐이면 **최신 자료를 못 찾았다고 알리기**

## 2. 검색에 시간 필터가 없었다 (직접 원인)

`배추 가격 시세`로 실제 검색해보니 상위 5건에 **2020년 6월 페이지**가 들어왔다.
오래된 자료가 그대로 컨텍스트에 실리니 답변도 낡을 수밖에 없었다.

```
필터 없음        → "배추 가격, 시세 2020년 6월 '상' 등급"   ← 6년 전
time_range=month → 전부 2026년 8월 자료
```

### 라우팅이 최신성 범위까지 결정

`검색어 | 기간` 형식으로 한 줄에 받아 Tavily의 `time_range`로 넘긴다.
**LLM 호출은 늘지 않는다** (기존 라우팅 호출에 얹었다).

| 질문 | 기간 판정 |
|---|---|
| 배추값 얼마야? | `day` |
| 오늘 환율 알려줘 | `day` |
| 이번주 주요 뉴스 뭐야 | `week` |
| 2026년 소상공인 지원사업 알려줘 | `month` |
| 파이썬 리스트 정렬법 | 검색 안 함 |

기간이 없거나 이상하면 필터 없이 검색한다.

## 결과

```
배추값 얼마야?
→ 알배기배추(전국 평균 소매가) 1포기당 4,017원 (2026년 8월 30일 기준)
   8월 평균가 3,329원보다 약 17.9% 높으며, 최근 150일 중 가장 비싼 시기

지금 몇 년도야?
→ 오늘은 2026년입니다. 현재 날짜는 2026년 8월 30일입니다.
```

날짜를 명시해 답하므로 사용자가 언제 기준 정보인지 바로 알 수 있다.
환율 테스트에서는 당일 수치가 없자 "안내가 어렵다"고 밝히고 `시점 불분명 자료`라고
구분까지 했다.
