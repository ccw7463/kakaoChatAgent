# 09. 남은 작업

## 미처리 항목과 판단 근거

### 1. `railway.json` → IaC 전환

**기한: 2026-12-01**

Railway의 Config as Code(`railway.json`)는 해당 날짜까지만 지원되고, 이후
`.railway/railway.ts` 형식으로 옮겨야 한다.

마이그레이션을 시도했으나 **npm 패키지(`railway`) 설치가 필요**하다. Python 저장소에
`package.json`과 `node_modules`를 들이는 것은 과하다고 판단해 되돌렸다.
기한을 `railway.json` 주석에 남겨두었다.

기한 전에 Railway가 파이썬 친화적 대안을 낼 가능성도 있다.

### 2. 대화 맥락 영속화 (`MemorySaver` → `PostgresSaver`)

현재 대화 이력은 프로세스 메모리에 있어 **재배포하면 초기화**된다. 사용자 개인정보와
선호도는 Supabase에서 복구되지만 직전 대화 흐름은 사라진다.

사용자가 "대화 맥락 날아가도 된다"고 판단해 진행하지 않았다. Postgres가 이미 있으므로
필요해지면 비교적 간단하다. **다음에 손댄다면 1순위.**

### 3. git 히스토리의 개인정보

`data/user_data.db`를 추적 해제했지만 **과거 커밋에는 그대로 남아 있다.**
공개 저장소이므로 이전 커밋을 열면 여전히 조회 가능하다.

사용자가 "추적 해제 + `.gitignore`만" 을 선택했다. 완전 제거가 필요하면
`git filter-repo` + force-push가 필요하며, 커밋 해시가 전부 바뀐다.

### 4. `google/gemini-3-flash-preview`

preview 딱지가 붙은 구버전이다. OpenRouter에 정식 버전들이 있고 가격도 비슷하다.

| 모델 | 입력 / 출력 (per 1M) |
|---|---|
| `google/gemini-3-flash-preview` (현재) | $0.50 / $3.00 |
| `google/gemini-3.7-flash` | $0.75 / $3.75 |
| `google/gemini-3.5-flash-lite` | $0.30 / $2.50 |

preview는 예고 없이 내려갈 수 있다. `.env`의 `LLM_MODEL` 한 줄로 교체 가능하다.

### 5. 무중단 배포

새 컨테이너 전환 중 몇 초간 502가 발생할 수 있어, 그 사이 들어온 메시지 한 건은
실패할 수 있다. 개인 봇 수준에서는 불필요하다고 판단했다.

### 6. 회상 저장 기준 (6자 휴리스틱)

인사말 오염을 막기 위해 6자 미만 발화를 저장하지 않는다. 데이터로 뒷받침된 기준이지만
휴리스틱이며, 6자 미만의 진짜 질문은 회상 대상에서 빠진다.

## 개선 여지

- **기간 판정 오분류** — 시세/뉴스 유형 중 `time_range` 판정이 어긋나는 케이스가
  남아 있을 수 있다. 실사용에서 낡은 정보가 보이면 해당 유형을 프롬프트에 추가하면 된다.
- **답변 길이** — 시스템 프롬프트에 700자 지침이 있으나 모델이 넘길 때가 있다.
  말풍선 분할로 안전하게 처리되지만, 지침을 더 강하게 걸 수도 있다.
